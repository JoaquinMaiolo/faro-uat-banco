# Banco de pruebas — UAT Alpha de FARO

Páginas congeladas para las sesiones de prueba con usuarios del proyecto final
**FARO** (UTN FRBA, 2026). Se publican acá sólo para que los testers puedan
abrirlas desde su propio teléfono durante la sesión.

> ⚠️ **Estas páginas NO son los sitios originales.** Son copias congeladas el
> 20/09/2026, y dos de ellas están **deliberadamente sin remediar** para poder
> medir el antes y el después. Llevan `noindex` y no deben enlazarse ni citarse
> como si fueran el sitio real.

Los nombres son neutros a propósito: el tester no debe saber cuál es la versión
remediada. El mapeo vive fuera de este repositorio.

Motor con el que se generaron las versiones remediadas: `faro-worker@4250c82`.
